    What this number measures

    vana-client keeps a list of everything its development journal (MODLOG.md) marks as not built, not known or not checked against the retail client: docs/re/modlog-gaps.md. This page counts the rows of that list by their status.

    • It is not a measure of all of retail. The list only holds gaps somebody wrote down. Retail features that were never noted are not in it, and one row can be a single flag or a whole window.
    • Built or answered counts rows whose status is built, matches retail, or answered by reading the DLL, including rows built but not yet seen in game.
    • Partly built rows ("built apart from …") count as not done yet.
    • Left out of the percentage: rows blocked because the server (LSB) never sends the data, known limitations that are accepted, and our own non-retail choices and upstream questions.
    • Rows the list moved to "Closed by later entries" were done before the list was written, so they are shown separately and not counted.
    • The list grows when a new retail client adds work (the November 2026 update added a section), so the percentage can drop even while work gets done.
